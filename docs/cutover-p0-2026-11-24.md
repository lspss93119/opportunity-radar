## 1. 切換前

1. **（選用）煙霧測試**：在試跑 checkout 執行 `git fetch && git checkout <HEAD>`，接著 `uv sync`，然後重啟 `radar-trial-p0`。跑 1–2 小時，確認 §4 的指標都正常。
2. **輪替 Telegram bot token（必做）**：舊版的 httpx INFO log 已經把 token 寫進 `runtime/*.log`，包括正式和試跑環境。
   - 到 BotFather 執行 `/revoke`，取得新的 token；
   - 更新 `~/.config/opportunity-radar/telegram.env`；
   - 清掉含有舊 token 的 log：

